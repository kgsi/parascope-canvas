# Parascope Canvas

[Parascope](https://parascope.design) のプロトタイプ・デモを配布するリポジトリです。

デザインとAIの交差点で生まれる実験的なプロトタイプ、インタラクション、ビジュアルサンプルを公開しています。

## 使い方

```bash
git clone https://github.com/kgsi/parascope-canvas.git
cd parascope-canvas/sample/<プロジェクト名>
```

各プロジェクトの `README.md` に個別の実行方法が記載されています。
