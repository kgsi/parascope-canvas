# Masonry

[Pretext](https://github.com/chenglou/pretext) を使った DOM リフローゼロの Masonry レイアウトデモ。

デザインに関する日本語の名言・格言を、仮想スクロール付きの Masonry グリッドで表示します。

## 技術

- **Pretext** (`@chenglou/pretext`) — DOM に触れずにテキスト高さを計算
- **Bun** — 開発サーバー・バンドラー
- **TypeScript**

## 起動

```bash
bun install
bun ./index.html
# http://localhost:3000
```
